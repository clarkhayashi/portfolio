# Nine-game field test

## What this build is for
One room of friends, nine quick games, and pretend-chip stakes that make reveals matter. Test variety without repeatedly teaching a new system. Repetition fatigue, waiting, creative pressure, setup friction and betting engagement are hypotheses, not validated claims about all party games.

## Run the first session
Four people, 20–30 minutes. Each opens the game on their own phone. One host chooses six rounds; use Minigames afterward to cover games the wheel did not select. A laptop public display is optional; the host opens it from the lobby.

Watch rather than coach. Note time to join, misunderstood actions, time spent idle, looking up at friends, and moments that get a reaction. Ask each person why they won/lost and whether judging felt fair. Compare Draft and Auction specifically.

## Coverage
- [ ] All nine games played: Same Brain, Ballpark, Food Court Draft, Food Auction, Drawing, Faker, Shadowbox, Keep It Going, Bad Answers.
- [ ] Two-, three-, four- and eight-player groups or follow-up sessions.
- [ ] iPhone Safari and Android Chrome: keyboard, drawing, audible beat, screen lock, return to same seat.
- [ ] Host disappears, another takes over after 30 seconds.
- [ ] Auction: all pass, last bidder, budget near empty, item naming, disconnected contestant.
- [ ] Bad Answers: missing answer, tied votes, skip prompt, pause, no self-vote.
- [ ] Comeback: accept, change dare, decline, timeout, once-only refill.
- [ ] Physical score disagreement: correction or refund, no endless wait.
- [ ] Shared display has no private role or unrevealed submissions.

## Acceptance
Join in under one minute without coaching; understand first action; complete the session without a blocker; explain results. A beautiful mockup does not satisfy these tests.

## Current verification
64 automated checks passed on September 24, including local request tests, cloud concurrency tests, auction fallbacks for 2/4/8, eight-player snake drafting, hidden answers, comeback consent, and physical dispute timeout. Browser two-tab auction bid/pass/item flow exercised. A 390px iframe layout has no horizontal overflow. Real iPhone/Android audio, lock/recovery and group enjoyment still need physical testing.

## Known limits
No native app or App Clip; no built-in voice call; human judging of physical actions and restaurant menu validity. Creative judging cannot remove friendship bias entirely. No real money. Drawing captions and sports packs are deferred. Private feedback intake still requires its scoped GitHub credential; the existing email route remains available. Figma has earlier incomplete imports; release screenshots are evidence, not a claim of complete editable synchronization.

Apple-supplied bezel DMGs display a license limited to Apple-only software mockups. They were not accepted or used for this cross-platform release. Neutral device frames are supplied instead.
